# Nivaaran – School Sanitation Accountability Prototype

**Seva First Innovation Challenge**

## 1. About the Project

Nivaaran is a digital accountability prototype designed to improve school sanitation and menstrual hygiene management.

It provides a structured way for schools to report sanitation-related problems, assign responsibility, track corrective actions, and independently verify whether reported problems have been resolved.

The goal is to ensure that essential facilities are not just reported as available but are actually accessible, functional, and maintained.

## 2. Problem Statement

Schools may face problems such as:
- Unavailability or insufficient stock of menstrual pads.
- Pads being locked away or inaccessible to students.
- Unusable girls' toilets.
- Lack of water and soap.
- Improper menstrual waste disposal facilities.
- Delays in repairing sanitation-related infrastructure.

These issues often lack a clear system for tracking responsibility, resolution, and independent verification.

## 3. Proposed Solution

Nivaaran introduces a structured accountability process:

1. **Report:** Schools submit weekly sanitation and menstrual hygiene checks.
2. **Detect:** Problems are identified through school reports and independent visits.
3. **Assign:** Each issue is assigned to the appropriate responsible person or authority.
4. **Track:** Deadlines and unresolved issues are monitored.
5. **Escalate:** Unresolved problems move to higher administrative levels.
6. **Verify:** Independent verifiers check whether corrective actions have actually worked.

## 4. Key Features

- Role-based dashboards for different administrative users.
- Weekly school sanitation and menstrual hygiene checks.
- Pad stock tracking and supply records.
- Reporting of sanitation and infrastructure problems.
- Independent verification by designated verifiers.
- Task assignment and responsibility tracking.
- Deadline monitoring and escalation of unresolved issues.
- Photo-based evidence submission.
- Activity history and audit logs.
- Offline-mode demonstration and simulated synchronization.
- Administrative settings for rules and deadlines.

## 5. User Roles

| Role | Responsibility |
|---|---|
| Headmaster | Submit weekly checks and report school problems |
| Verifier 1 & 2 | Independently inspect schools and verify fixes |
| Block Education Officer | Manage and assign unresolved problems |
| Block Maintenance Owner | Handle infrastructure-related repairs |
| Block Supply Owner | Handle menstrual pad supply issues |
| District Education Officer | Monitor and handle escalated problems |
| District Supply Owner | Handle escalated supply issues |
| Platform Administrator | Configure rules and time limits |

## 6. Technology Stack

- **HTML5:** Application structure
- **CSS3:** Responsive user interface and styling
- **JavaScript:** Application logic, interactions, role-based workflows and task management

The prototype does not require a backend server or a database to run.

## 9. Demonstration Data and Limitations

- The prototype uses fictional demo schools and sample data.
- It is intended to demonstrate the proposed workflow and user experience.
- Data is stored locally in the browser.
- Offline mode and synchronization are demonstrated simulations, not a live multi-device synchronization service.
- It is not connected to actual government school databases or administrative systems.
- It is not a production-ready application.

## 10. Future Scope

- Backend integration with a secure database.
- Secure authentication and role-based access control.
- Real-time synchronization across devices.
- Government-authorized pilot implementation.
- Integration with existing school monitoring systems, subject to approval.
- Improved reporting and administrative analytics.

## 11. Privacy and Safety

The proposed system follows a privacy-conscious approach. It is designed to track facility-level issues rather than collect students' personal health information.

The prototype uses fictional data and should not be used to enter real student information or sensitive personal details.
